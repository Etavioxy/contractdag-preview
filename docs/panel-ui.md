# vscode-contractdag-preview — Panel UI

- **本文档范围**：webview 里画什么、细节随比例怎么收、视图状态怎么存活，以及缩放与滚动的阻尼。坐标怎么算归 `graph-layout.md`，手势与 VS Code 接缝归 `vscode-integration.md`。
- **webview 只收模型**：节点框、边、折好的正文行都由宿主算好整份下发；webview 不解析文本、不持有文法知识。
- **刷新是重发整份**：文档一变就重算并重发，不做增量 diff。
- **视图状态不回写文档**：缩放与滚动只影响呈现，模型侧可写状态为零，见 `spec.md` §真源与派生。

## 三层状态

| 状态 | 归属 | 生命周期 |
|---|---|---|
| 节点、边、正文行 | 不存，每次由文档算出 | 随文档内容 |
| 展开集合、高亮 | 宿主，按文档 URI 存 | 面板 dispose 时清 |
| `{scale, scrollX, scrollY}` | webview | 面板销毁即消失 |

重发时只换第一层：比例与滚动原样保留，越界才钳制；首次渲染才按适配算比例。

## 节点

- 节点只有一种尺寸 160×56：名字居中偏上，种类居中偏下，右上角一个角标。
- 名字超出可用宽度（框宽减去左右各 12 的内缩）就按字符截断，末尾留省略号：框宽固定，长名字宁可少几个字也不越过边框。
- 正文不进框：框一长高就要顶开层距里的弧线与产物标签，展开还会让整图重排、坐标跳动；正文改由浮层承载，见本文 §正文浮层。
- 正文按 26 半角列折行，全角与 CJK 记两列；`path` 每行带 `path  ` 前缀，`destination` 保持原句。

## 密度

比例越小，越早收掉小字：

| 比例 | 画到哪一层 |
|---|---|
| ≥ 0.75 | 边标签 |
| 0.55 – 0.75 | 只留种类 |
| < 0.55 | 只留名字与边框 |

角标与边框不参与分档，任何比例都画；正文在浮层里，不受画布分档影响。

阈值由字号反推：名字 13px、种类与边标签 11px，比例 0.75 时 11px 落到 8.25px，比例 0.55 时落到 6px。

## 常量出处

排版常量在 `payload.ts`（`contentColumns`、`headerHeight`）、`scene.ts`（字号、名字与角标的落点，`nameInset`）、`text.ts`（`halfWidthEm`、`widthSafety`，估宽与截断）、`body-layer.ts`（浮层的贴边距与内缩）与 `layout.ts`（`labelHeight`、`labelSpacing`、`padding`），比例、步进、阻尼与密度阈值在 `viewport.ts`（`scaleLimits`、`scaleStep`、`dampingFactor`、`densityThresholds`）。本文的数字与这几处常量同值。

## 缩放与滚动的边界

- 比例落在 0.5 到 3 之间，每次步进乘 1.1。
- 适配宽度：宽度贴合视口且不超过 1，小图不放大。高度超出就让纵向滚动负担——取两个方向的较小比例会让内容永远装进视口，可滚距离恒为 0。
- 滚动范围是「内容边界 + 每个方向半个视口的余量」，下界允许为负。只按内容算范围时，内容一旦贴合视口可滚距离就是 0，双指滑行与拖动会整块失效。
- 相机用 `ctx.setTransform` 把比例与位移一次写进画布，不用 `scrollLeft`：`scrollLeft` 不接受负值，等于把余量里向下、向左的那一半丢掉。

## 阻尼

- 只有程序触发的位移走缓动：缩放、适配宽度。朝目标值指数逼近，每帧吃掉剩余距离的 18%，约十二帧（60fps 下 200ms）走完九成，收在 0.0005 以内即停。
- 滚轮与拖动直接跟手，不叠阻尼：触控板自己带惯性与阻尼，再逼近一层就是双份惯性，表现为滑不停、也停不准。
- 缩放的锚点是触发瞬间的指针位置；滚动按比例进度插值，缩放全程锚点下的内容不动。
- 拖动时指针位移与画布位移一比一。

## 边

- 边是一段三次贝塞尔曲线：两端沿流动方向出入，控制点各占一半。密集交叉时直线会连成一团，弧线能把来路和去向分得开。
- 箭头三个顶点由宿主算好，尖端贴在目标框边上，朝向取曲线在终点的切向；相邻两层的框常不在同一列，按轴对齐画三角形会和线错开一个夹角。
- 产物标签落在出发缝里：解 `t` 使曲线的流动坐标到该缝中点，再按道号沿流动方向偏移；只有会撞的标签互相错道，其余留在中线上。道数与道号见 `graph-layout.md` §层距与格位。
- 撞不撞按字形高度 11px 算，4px 描边垫底不进碰撞框；宽度在宿主侧按列估算（拿不到字体度量）——半角记 0.55 个字号、全角与 CJK 记两列，另留 10% 余量：估窄的代价是叠字，估宽只是多占位。
- 保证之一：同一缝内的标签互不重叠——度量由上面的字号与估宽规则给出。
- 保证之二：标签只按道号在交叉方向偏移，仍贴着自己的曲线；与别的曲线相交时不保证不遮挡，4px 描边垫底只保读得清。

## 缺陷标记

- 环：环上的边连箭头一起标红。
- 断头节点：框描边转灰；根节点不止一个时，多出来的那个根同样转灰。
- 变更节点缺 `path`：左上角一个角标。
- 产物重名：首个产物标签旁一个角标。
- 连线引用了未声明的节点：这条边画不出来，只进缺陷清单。

## 正文浮层

- 展开的正文住 DOM，可选中、可查找：贴节点右侧 8px，右边放不下翻到左侧，纵向钳在视口内。
- 浮层随相机一起缩放，左上角是缩放锚点：比例变了而浮层不变，就会和图的尺度对不上。
- 拖动与缩放时只挪位置、不重建节点，选中区与滚动位置都保得住。
